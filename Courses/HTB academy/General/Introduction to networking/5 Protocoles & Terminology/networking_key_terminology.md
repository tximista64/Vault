# Networking Key Terminology

Glossaire des protocoles réseau essentiels — à consulter régulièrement et à enrichir au fil des modules.

## Sécurité & Chiffrement

| Protocole | Acronyme | Description |
|---|---|---|
| Wired Equivalent Privacy | WEP | Ancien protocole de sécurité Wi-Fi — obsolète |
| Wi-Fi Protected Access | WPA | Protocole de sécurité sans fil par mot de passe |
| Temporal Key Integrity Protocol | TKIP | Protocole de sécurité sans fil — moins sécurisé que WPA2 |
| Pretty Good Privacy | PGP | Chiffrement d'emails, fichiers et données |
| Internet Protocol Security | IPsec | Communication chiffrée sur réseau — utilisé dans les VPNs |
| Internet Key Exchange | IKE | Établit une connexion sécurisée entre deux machines (VPNs) |
| Virtual Private Network | VPN | Tunnel chiffré vers un autre réseau via Internet |
| Point-to-Point Tunneling Protocol | PPTP | Tunnel sécurisé pour accès distant |
| Generic Routing Encapsulation | GRE | Encapsule les données dans un tunnel VPN |

## Protocoles d'application

| Protocole | Acronyme | Description |
|---|---|---|
| Secure Shell | SSH | Accès distant sécurisé et exécution de commandes |
| File Transfer Protocol | FTP | Transfert de fichiers entre systèmes |
| Simple Mail Transfer Protocol | SMTP | Envoi et réception d'emails |
| Hypertext Transfer Protocol | HTTP | Transfert de données web (client-serveur) |
| Network News Transfer Protocol | NNTP | Distribution de messages dans les newsgroups |
| Session Initiation Protocol | SIP | Établissement de sessions voix/vidéo/multimédia sur IP |
| Voice Over IP | VOIP | Appels téléphoniques via Internet |
| Remote Shell | RSH | Exécution de commandes sur une machine Unix distante |

## Partage de ressources réseau

| Protocole | Acronyme | Description |
|---|---|---|
| Server Message Block | SMB | Partage de fichiers, imprimantes et ressources réseau |
| Network File System | NFS | Accès à des fichiers distants via le réseau |

## Gestion réseau

| Protocole | Acronyme | Description |
|---|---|---|
| Simple Network Management Protocol | SNMP | Gestion des équipements réseau |
| Network Time Protocol | NTP | Synchronisation de l'heure entre machines |
| Cisco Discovery Protocol | CDP | Découverte et gestion des équipements Cisco |
| Microsoft Baseline Security Analyzer | MBSA | Détection de vulnérabilités sur systèmes Windows |
| Systems Management Server | SMS | Gestion de réseaux, systèmes et mobiles |

## Routage

| Protocole | Acronyme | Description |
|---|---|---|
| Routing Information Protocol | RIP | Protocole de routage à vecteur de distance (LAN/WAN) |
| Open Shortest Path First | OSPF | IGP — routage intra-AS par état de liens |
| Interior Gateway Routing Protocol | IGRP | IGP propriétaire Cisco |
| Enhanced Interior Gateway Routing Protocol | EIGRP | Protocole de routage avancé à vecteur de distance |

## Switching & LAN

| Protocole | Acronyme | Description |
|---|---|---|
| Virtual Local Area Network | VLAN | Segmentation logique d'un réseau |
| VLAN Trunking Protocol | VTP | Gestion des VLANs sur plusieurs switches (Layer 2) |
| Spanning Tree Protocol | STP | Évite les boucles dans les réseaux Ethernet Layer 2 |
| Hot Standby Router Protocol | HSRP | Redondance de routeur (Cisco) |
| Virtual Router Redundancy Protocol | VRRP | Attribution automatique de routeurs de secours |

## Authentification

| Protocole | Acronyme | Description |
|---|---|---|
| Extensible Authentication Protocol | EAP | Framework multi-méthodes d'authentification |
| Lightweight EAP | LEAP | EAP propriétaire Cisco pour réseaux sans fil |
| Protected EAP | PEAP | Tunnel chiffré pour authentification sans fil |
| TACACS | TACACS | Authentification, autorisation et accounting centralisés |

## Réseau & Adressage

| Protocole | Acronyme | Description |
|---|---|---|
| Network Address Translation | NAT | Permet à plusieurs hôtes privés de partager une IP publique |
| Uniform Resource Identifier | URI | Syntaxe d'identification d'une ressource Internet |
| Uniform Resource Locator | URL | Sous-ensemble d'URI incluant protocole et domaine |
| Carriage Return Line Feed | CRLF | Caractères de fin de ligne dans certains formats texte |

## Industriel & Divers

| Protocole | Acronyme | Description |
|---|---|---|
| SCADA | SCADA | Contrôle et supervision de processus industriels |
| AJAX | AJAX | Technique web pour pages dynamiques (JS + XML/JSON) |
| ISAPI | ISAPI | API pour extensions de serveurs web haute performance |
