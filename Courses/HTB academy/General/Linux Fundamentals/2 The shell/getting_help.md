# Getting Help

## Méthodes pour obtenir de l'aide

| Commande | Usage | Description |
|---|---|---|
| `man <tool>` | `man ls` | Manuel complet — navigation avec `h`, quitter avec `q` |
| `<tool> --help` | `ls --help` | Options résumées — standard Linux |
| `<tool> -h` | `curl -h` | Version courte — certains outils seulement |
| `apropos <keyword>` | `apropos sudo` | Recherche dans les descriptions des man pages par mot-clé |

## Ressource externe

**https://explainshell.com/** — décompose et explique une commande complexe en langage clair.

> Réflexe à prendre : toujours commencer par `man` ou `--help` avant de chercher ailleurs.
