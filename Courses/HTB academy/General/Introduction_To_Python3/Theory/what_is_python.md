# What is Python

## Présentation

Ce module couvre les bases du scripting Python 3, accessible aussi bien aux profils IT qu'aux débutants complets. L'objectif : écrire des scripts petits mais utiles.

## Pourquoi apprendre Python ?

Python est l'un des langages de scripting les plus populaires. Ses cas d'usage principaux :

- **Automation** de tâches répétitives
- Développement d'**outils**
- InfoSec : nombreux **PoC** (Proof of Concepts) et outils de **penetration testing** écrits en Python
- Traitement et analyse de grandes quantités de données
- Création de services interactifs

Sa simplicité attire quand il faut "juste écrire quelque chose rapidement", mais sa flexibilité et son écosystème communautaire le rendent aussi viable pour de grands projets.

## Caractéristiques techniques

- **Interpreted language** : le code n'est pas compilé en machine code (contrairement au C) — il est exécuté directement par l'interpréteur Python.
- **High-level language** : pas besoin de gérer la mémoire, les system calls, etc.
- **General-purpose** et **multi-paradigm** : utilisable pour la plupart des besoins, compatible avec différents styles de programmation.

## Style de programmation

Le module effleure la programmation **orientée objet** (OOP), qui simplifie le raisonnement sur le code. Python est réputé pour sa lisibilité, notamment grâce à sa ressemblance avec l'anglais et ses exigences strictes en matière d'**indentation**.

## Prérequis et recommandations

- Python 3 installé et présent dans le `PATH` (une VM préconfigurée est fournie).
- **Taper le code à la main** plutôt que de copier-coller — meilleure mémorisation et prise en main.
- Explorer et expérimenter les techniques présentées.
